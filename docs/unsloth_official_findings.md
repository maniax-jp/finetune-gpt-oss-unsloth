# Unsloth公式ドキュメント分析：追加の重大な問題発見

## 📋 公式ドキュメントの重要な推奨事項

出典: https://docs.unsloth.ai/models/gpt-oss-how-to-run-and-fine-tune

---

## 🚨 **最も重大な発見：推論能力の劣化**

### 公式推奨事項

> **"When fine-tuning with non-reasoning datasets, maintain reasoning capability by using at least 75% reasoning and 25% non-reasoning data ratio."**

### 現在のデータセット構成

**分析結果:**
```
データセット: 455サンプルの単純なQA
形式: 質問 → 短い事実的回答

例:
Q: "高市早苗さんの生年月日は？"
A: "1961年3月7日生まれです。"

Q: "高市早苗さんの出身大学は？"
A: "神戸大学経営学部を卒業しています。"
```

**問題点:**
- **推論（reasoning）データ: 0%**
- **非推論（non-reasoning）データ: 100%**

### 推奨比率との比較

| 項目 | 推奨 | 現状 | 差分 |
|------|------|------|------|
| 推論データ | **≥75%** | **0%** | **-75%** ❌ |
| 非推論データ | ≤25% | 100% | +75% ❌ |

---

## 🎯 **この問題が性能悪化を引き起こすメカニズム**

### 1. **推論能力の完全喪失**

GPT-OSS-20Bは元々**推論特化型**モデルです：
- STEM（科学・技術・工学・数学）に強い
- コーディング能力が高い
- 論理的思考が得意

**現在のファインチューニング:**
```
455サンプル × 25エポック = 11,375回
すべて「暗記型」の単純QA
```

→ **推論能力が完全に上書きされる**

### 2. **「暗記」vs「理解」のバランス崩壊**

#### 理想的な学習パターン
```
推論データ（75%）: モデルが「考え方」を学ぶ
例:
Q: "高市早苗さんの政策と安倍晋三さんの政策の共通点は？"
A: "両者とも保守的な経済政策を重視しており、具体的には...
   [論理的な比較と分析]
   このような共通点から、..."

非推論データ（25%）: モデルが「事実」を覚える
例:
Q: "高市早苗さんの生年月日は？"
A: "1961年3月7日生まれです。"
```

#### 現在の学習パターン（問題）
```
非推論データ（100%）: モデルが「暗記」のみ
↓
推論能力の劣化
↓
基本的事実すら正確に回答できない矛盾
```

### 3. **過学習のメカニズム再考**

**新たな理解:**
```
問題の本質 = MoE過学習 + 推論能力喪失

1. 暗記特化の学習（推論0%）
2. 25エポックの繰り返し
3. Dropout = 0
4. モデルが「パターンマッチング」に特化
5. 基本的事実の「理解」ではなく「表面的な暗記」
6. 新しい質問形式に対応できない
7. 結果: エラー増加
```

## 📊 **エビデンス：推論能力の喪失を示す具体例**

### 第4次モデルの応答パターン

#### パターン1: 事実の混同
```
Q: "高市早苗さんの出身地はどこですか？"
A: "岩手県奥州市です。"  ❌

分析: 他の政治家の情報と混同している
→ 推論能力があれば「高市」+「奈良」の関連性を理解できるはず
```

#### パターン2: 時系列の理解不足
```
Q: "高市早苗さんの初当選はいつですか？"
第3次: "1993年" ✅（正確）
第4次: "2009年" ❌（16年のずれ）

分析: 時系列を論理的に推論できていない
→ 生年月日（1961年）と初当選（2009年）の矛盾に気づけない
```

#### パターン3: 論理的整合性の欠如
```
Q: "高市早苗さんの学歴について教えてください"
A: "日本大学法学部を卒業し、同校で政治経済学修士号を取得しました。"

分析: 「法学部」と「政治経済学修士」の組み合わせが不自然
→ 推論能力があれば矛盾を検出できるはず
```

## 🔍 **Unsloth公式の他の推奨事項との比較**

### 1. **推論温度設定**

**公式推奨:**
```python
temperature = 1.0
top_p = 1.0
top_k = 0
```

**現在の設定（評価時）:**
```python
temperature = 0.7  # 低すぎる
top_p = 0.9
top_k = 50  # 公式は0推奨
```

**問題:**
- 低温度 → 多様性が低い → パターン固定化

### 2. **コンテキスト長**

**公式推奨:**
```
最小: 16,384 tokens
最大: 131,072 tokens
```

**現在の設定:**
```python
MAX_SEQ_LENGTH = 2048  # 8倍も短い！
```

**問題:**
- 短いコンテキスト → 複雑な推論ができない
- QAデータも短い → 推論能力を訓練できない

### 3. **メモリ要件**

**公式情報:**
```
QLoRA: 14GB VRAM（gpt-oss-20b）
BF16 LoRA: 44GB VRAM
```

**現在の環境:**
```
RTX 5090: 32GB VRAM
→ QLoRAで十分（現状問題なし）
```

## 📚 **結論**

**データセットは「無実」ではなく、むしろ「主犯」でした。**

しかし、それは**データの質**の問題ではなく、**データの構造**の問題です。

GPT-OSS-20Bのような推論特化型MoEモデルに対して、100%暗記型データでファインチューニングを行ったことが、性能悪化の最大の原因でした。

**公式ドキュメントの推奨（75%推論データ）を完全に無視した結果、推論能力を失ったモデルは、基本的な事実すら正確に回答できなくなりました。**

即座に、推論型データの追加とハイパーパラメータの最適化を行うべきです。
