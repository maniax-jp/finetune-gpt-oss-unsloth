### 3. 比較データセット作成

**実施事項**:
- 悪い応答と正しい応答のペアを作成
- DPO (Direct Preference Optimization) 形式でエクスポート
- スクリプト: `scripts/evaluation/create_comparison_dataset.py`

**成果物**:
- ✅ JSON形式: `data/comparison/comparison_dataset_20251020_151239.json`
- ✅ JSONL形式 (DPO用): `data/comparison/dpo_dataset_20251020_151239.jsonl`
- ✅ 総ペア数: 7ペア

**データセット構造** (JSONL形式):
```json
{
  "prompt": "質問文",
  "chosen": "正しい応答",
  "rejected": "誤った応答（モデルの実際の出力）"
}
```

**サンプル**:
```json
{
  "prompt": "高市早苗さんの出身地はどこですか？",
  "chosen": "高市早苗さんの出身地は奈良県です。",
  "rejected": "愛知県名古屋市出身です。"
}
```

## 📈 分析結果

### モデルの強み
1. ✅ **政策・主張に関する応答**: 経済政策、安全保障政策、エネルギー政策などは適切
2. ✅ **複雑な質問への対応**: 「首相になったらどんな政策を実施するか」などの推論質問に適切に回答
3. ✅ **比較質問への対応**: 他の政治家との違いを説明できる
4. ✅ **一般的な知識**: 政治的立場（保守派）、派閥（安倍派）などは正確

### モデルの弱み
1. ❌ **基本的な事実の誤り**: 生年月日、出身地、学歴、選挙区など、最も基本的な情報に誤りが多い
2. ❌ **数値・固有名詞の不正確さ**: 年号、地名、大学名などの具体的な情報に弱い
3. ❌ **過度な一般化**: 短い応答で済ませようとする傾向

### 誤りの原因分析
1. **トレーニングデータの不足**: 基本情報に関するQAペアが少なかった可能性
2. **事実の混同**: 他の政治家の情報と混同している
3. **幻覚（Hallucination）**: 存在しない情報を生成

## 🎯 Week 5への提言

### DPOトレーニングの方針

**目的**: 事実の正確性を向上させる

**データセット**:
- 現在: 7ペア（基本情報中心）
- **推奨**: 100-200ペアに拡張
  - 基本情報: 30ペア
  - 政策・主張: 30ペア
  - 実績・業績: 20ペア
  - その他: 20ペア

**追加データ収集方法**:
1. 既存の301サンプルから誤り応答を抽出
2. 意図的に誤った応答を生成（温度を上げて多様性を確保）
3. 人手で正しい応答と誤った応答のペアを作成

**トレーニング設定**:
- アルゴリズム: DPO (Direct Preference Optimization)
- ベースモデル: 第2次ファインチューニング済みモデル
- エポック数: 1-3（過学習防止）
- 学習率: 1e-5 〜 5e-6（SFTより低め）
