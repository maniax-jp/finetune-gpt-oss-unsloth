## 7. 技術的洞察

### 7.1 データ比率の重要性

**発見**: MoEモデルのファインチューニングでは、**データパターンの一貫性が極めて重要**

- 第6次: 9.9%のanalysisチャンネル → 0% 認識率
- 第7次: 100%のanalysisチャンネル → 100% 認識率

**教訓**:
- 新しいパターン（analysisチャンネル）を学習させる場合、**全データに適用する必要がある**
- 少数のサンプルだけでは、モデルは新しいパターンを学習しない

### 7.2 train_on_responses_only の影響

`train_on_responses_only=True` の設定により:
- アシスタントの出力のみでloss計算
- 短い回答（非推論データ）のloss寄与度が小さい
- 長い回答（推論データ）のloss寄与度が大きい

**しかし**:
- データ数の多寡の影響が大きい
- 9.9%の推論データでは不十分
- 100%の推論データで初めて効果を発揮

### 7.3 自動生成analysisチャンネルの有効性

**懸念**: 自動生成されたanalysisの品質は手動作成より劣るのでは？

**結果**: 自動生成でも十分に効果的

**理由**:
1. 固有名詞の日英対応が明示されている
2. テンプレート化された構造が一貫している
3. モデルは「パターン」を学習する

**結論**:
- 品質よりも**一貫性**と**カバレッジ**が重要
- 自動生成でも100%のカバレッジがあれば効果的
